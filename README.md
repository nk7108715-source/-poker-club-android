
# 🎮 Poker Club

Poker Club is a virtual-chip Texas Hold'em poker game prototype.

## Features
- Play as Guest
- Signup and Login demo
- 1,000,000 virtual starting chips
- Multiple table options
- Private room code demo
- Daily, Weekly and Monthly leaderboard demo
- Mobile-friendly interface

## Game Rules
- Texas Hold'em poker
- Up to 8 players per table
- Virtual chips only
- No real-money betting

## Technology
- HTML
- CSS
- JavaScript

## Project Status
This is an early UI prototype. Online multiplayer, real Firebase authentication, secure chip management, proper poker rules, voice chat and working leaderboards still need to be implemented.

## Future Plans
- Firebase Authentication
- Firestore player profiles
- Online multiplayer tables
- Private rooms with join codes
- Daily rewards and leaderboards
- Voice chat
- Optional ads for virtual-chip rewards
